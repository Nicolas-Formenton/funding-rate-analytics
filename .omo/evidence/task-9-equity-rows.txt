## Notes & Caveats
---------------------------------------------------------------------
- Task 2 (BitMEX .SPYPERP) and Task 5 (Hyperliquid SPY main perp)
  negative results are still in effect for those specific symbols;
  this task expands coverage by adding the HIP-3 xyz dex (not
  known when T2/T5 ran) and Binance TradFi perps.
- The HL xyz /funding endpoint does not return a mark or index
  price, so those columns are NULL for hyperliquid_xyz rows. The
  Binance /fapi/v1/fundingRate endpoint does return markPrice
  (real stock/index prices, e.g. AAPL ~$300, SPY ~$750) but no
  historical indexPrice. BitMEX /funding returns neither.
- The HL xyz dex is reachable as a separate HIP-3 deployment;
  the main HL perp universe still has 0 equity perps as of
  2026-06-16.
- Idempotency: a UNIQUE INDEX on (ts, venue, symbol) is created
  on first run; subsequent runs use ON CONFLICT DO NOTHING, so
  re-running the script does not duplicate rows. Verified by
  test_idempotent (loader run twice → row count unchanged).
- Exit code 0 if at least one venue contributed data (regardless
  of whether the contribution was new or pre-existing). Exit
  code 1 only if the table is empty after the run.
