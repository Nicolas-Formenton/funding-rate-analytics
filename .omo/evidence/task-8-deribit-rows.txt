8. Notes & design decisions
---------------------------
  - Public JSON-RPC endpoint only, no API keys, no auth headers.
  - Pagination: 7-day windows (~168 records each, well under the
    ~744-record Deribit response cap; the cap was confirmed empirically
    by sending 1-month and 1-year windows -- both returned 744).
  - Backoff: 1s, 2s, 4s, 8s on HTTP 429/5xx and JSON-RPC error
    responses; 10 rapid sequential requests showed no throttling, but
    the backoff is wired in for safety.
  - mark_price is stored NULL on every row because Deribit's response
    schema for get_funding_rate_history does not include it.  This is
    a known gap that the dbt staging layer must handle (e.g. leave
    NULL or pull from a separate mark-price endpoint).
  - Idempotency: per-instrument DELETE then re-insert, all in a single
    Postgres connection (truncate+reload semantics).  Safe to re-run.
