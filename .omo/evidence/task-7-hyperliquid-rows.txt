## Notes
- HL API caps responses at 500 records per call. The loader uses 20-day forward
  pagination windows (~480 records/window) starting from the earliest known HL
  data point (2023-05-12 00:00 UTC, timestamp 1683849600000).
- Downsampling rule: keep the record with the largest `time` per (coin, hour-bucket)
  and rewrite that `time` to the start of the hour. This makes the output
  idempotent and diff-friendly across re-runs.
- mark_price and open_interest are persisted as NULL — the public fundingHistory
  payload only carries fundingRate, premium, and time.  Those are the only
  fields the loader trusts from Hyperliquid for this table.
- Retries with exponential backoff (max 4, 1→2→4→8s) handle transient HTTP errors.
- Inter-call sleep of 150 ms keeps the loader polite to the public endpoint.
